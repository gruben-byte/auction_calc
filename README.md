# Auction Bid Tracker

A private, offline-capable iPhone web app. Bid data stays in the browser on the device.

## Install on iPhone
1. Upload this folder to any HTTPS static host (GitHub Pages, Cloudflare Pages, Netlify, or your own server).
2. Open the resulting address in Safari once while online.
3. Tap Share > Add to Home Screen, leave **Open as Web App** enabled, then tap Add.
4. Launch it once while online so the offline files are cached. It can then be used without internet.

## Controls
- Presets: +$1,000, +$5,000, +$10,000
- Custom adjustment: key in an amount and tap + or -
- Set current bid: key in an amount and tap SET while in Adjust bid mode
- Set ceiling: choose Set limit, key in your maximum and tap SET
- Undo restores the previous bid
- On the market toggles a visible auction marker

Important: test the app before relying on it at an auction. Keep your independently determined walk-away limit.
